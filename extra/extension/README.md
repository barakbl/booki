# 📚 Booki — Browser Extension

A cross-browser extension (Chrome + Firefox) that gives Booki two superpowers in your browser:

1. **Quick picker** — a side-panel / sidebar list of your Booki items with fzf-style fuzzy / substring search. Hit **Alt+Shift+B** (rebindable) to open. Enter opens the highlighted item in the current tab; ⌘/Ctrl+Enter opens it in a new tab.
2. **Right-click → Add to Booki** — adds a link, page, or image to your Booki via `POST /api/link`, with a green ✓ badge on the toolbar icon and a top-right toast on the page.

---

## Layout

```
extra/extension/
├── build.sh              # assembles per-platform bundles into dist/
├── src/
│   ├── shared/           # cross-platform UI + background-core
│   │   ├── icons/
│   │   ├── sidebar.{html,js,css}     # picker
│   │   ├── options.{html,js,css}     # settings page
│   │   ├── content.js                # injected toast helper
│   │   └── background-core.js        # context menus, fetch+cache, message handling
│   ├── chrome/
│   │   ├── manifest.json             # MV3, side_panel + sidePanel permission
│   │   └── platform.js               # uses chrome.sidePanel.*
│   └── firefox/
│       ├── manifest.json             # MV3, sidebar_action + gecko id
│       └── platform.js               # uses chrome.sidebarAction.*
└── dist/                 # generated by build.sh; gitignored
    ├── chrome/
    └── firefox/
```

The shared code uses `chrome.*` exclusively — Firefox aliases it, so the same picker / options / content scripts run in both browsers. The only platform-specific glue is in `platform.js` (how to open the side panel vs. the sidebar) and `manifest.json`.

---

## Build

```bash
bash extra/extension/build.sh
```

The build is literally `cp` — no bundler, no transpiler.

Outputs:
- `dist/chrome/` — load via `chrome://extensions/` → **Developer mode** → **Load unpacked**.
- `dist/firefox/` — load via `about:debugging` → **This Firefox** → **Load Temporary Add-on…** → pick `dist/firefox/manifest.json`.

> **Firefox note:** `about:debugging` add-ons are unloaded when Firefox restarts. For a persistent install, sign the extension via [AMO](https://addons.mozilla.org/) or use Firefox Developer Edition with `xpinstall.signatures.required = false`.

## Settings

| Setting | What it does |
|---------|-------------|
| **Booki host** | Default `http://127.0.0.1:8765`. Change if Booki runs elsewhere. |
| **Show in picker** | Which item kinds appear in the picker. Default: just `bookmark`. The kind list is auto-discovered from your live Booki items. |

The fuzzy / substring toggle lives **inside** the picker (top-right of the search input). The choice is persisted.

---

## Caching

The picker list is cached in `chrome.storage.local` indefinitely. It's re-fetched in the background after 24h, after **Save** in Settings, after a successful **Add to Booki**, or when you hit ↻ in the picker header.

---

## Keyboard shortcut

Default: **Alt+Shift+B**.

- Chrome: rebind via `chrome://extensions/shortcuts`.
- Firefox: rebind via `about:addons` → ⚙ → **Manage Extension Shortcuts**.

In the picker:

| Key | Action |
|-----|-------|
| `↑` / `↓` | Move selection |
| `Enter` | Open in current tab |
| `⌘ Enter` / `Ctrl+Enter` | Open in new tab |
| `Esc` | Clear search |

## Platform differences (what `platform.js` covers)

| Concern | Chrome | Firefox |
|---|---|---|
| Open the picker UI | `chrome.sidePanel.open({windowId})` | `chrome.sidebarAction.toggle()` |
| Open on toolbar-icon click | `chrome.sidePanel.setPanelBehavior({openPanelOnActionClick: true})` | `chrome.action.onClicked` → `sidebarAction.toggle()` |
| Manifest UI key | `"side_panel"` | `"sidebar_action"` |
| Required manifest fields | — | `"browser_specific_settings.gecko.id"` |
| MV3 service worker | required | supported (Firefox 121+) |
